```python
import sys
from collections import deque

def main() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    deg = [0] * n

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
        deg[u] += 1
        deg[v] += 1

    # initial queue of leaves
    q = deque([i for i in range(n) if deg[i] == 1])
    removed = [False] * n
    rounds = 0

    while q:
        rounds += 1
        next_q = deque()
        while q:
            node = q.popleft()
            if removed[node]:
                continue
            removed[node] = True
            for nb in adj[node]:
                if removed[nb]:
                    continue
                deg[nb] -= 1
                if deg[nb] == 1:
                    next_q.append(nb)
        q = next_q

    print(rounds)

if __name__ == "__main__":
    main()
```

**Explanation**

* The graph is represented by an adjacency list `adj`.
* `deg[i]` stores the current degree of vertex `i`.
* Initially all vertices with degree `1` (leaves) are placed in a queue `q`.
* While the queue is not empty, we remove all vertices currently in it (this forms one “group”).
  * For each removed vertex we decrease the degree of its neighbours.
  * If a neighbour’s degree becomes `1`, it is scheduled for removal in the next round.
* The counter `rounds` is increased once per batch of removals, which equals the number of groups that are kicked out.
* The algorithm runs in \(O(n+m)\) time and uses \(O(n+m)\) memory, far more efficient than repeatedly scanning all vertices.

**Optimised solution – C#**

```csharp
using System;

class FastScanner
{
    private string[] _buffer;
    private int _index;

    public FastScanner()
    {
        _buffer = Array.Empty<string>();
        _index = 0;
    }

    public int NextInt()
    {
        while (_index >= _buffer.Length)
        {
            string line = Console.ReadLine();
            if (line == null) throw new InvalidOperationException("Unexpected end of input");
            _buffer = line.Split(new[] { ' ', '\t' }, StringSplitOptions.RemoveEmptyEntries);
            _index = 0;
        }
        return int.Parse(_buffer[_index++]);
    }
}

class Program
{
    static void Main()
    {
        var fs = new FastScanner();

        int n = fs.NextInt();                 // size of the array
        bool[] seen = new bool[n + 1];        // 1-based index

        for (int i = 0; i < n; i++)
        {
            int value = fs.NextInt();        // read the element
            if (value >= 1 && value <= n)   // only numbers inside 1..n matter
                seen[value] = true;          // mark that the value exists
        }

        int missing = 0;
        for (int i = 1; i <= n; i++)
            if (!seen[i])
                missing++;                  // i is absent – one change needed

        Console.WriteLine(missing);
    }
}
```

**Explanation of optimisation**

- Uses a boolean array (`seen`) instead of counting occurrences; we only need to know if a value appears at least once.
- Skips out-of-range values (`<1` or `>n`) immediately – they never help to form the permutation.
- Counts missing numbers in a single linear pass; each missing number equals one required change.
- Reads input lazily with `FastScanner`, handling arbitrary line breaks without allocating large temporary arrays.
- Overall time complexity is `O(n)` and memory usage is `O(n)` (= 5001 booleans), which is optimal for the given constraints.
